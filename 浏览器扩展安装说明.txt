剧单助手 · 红果连接 0.1.9

用途
配合剧单工作台0.6.2，使用你原来 Chrome 窗口中的红果登录。扩展仅连接你明确选中的红果后台标签页；软件关闭后仍可正常使用原窗口。
此版只支持普通 Chrome 窗口，不在无痕窗口运行。Chrome 重启后需要重新选择标签页并连接。

第一次连接
1. 在 Chrome 打开 chrome://extensions，开启「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择含 manifest.json 的本说明目录，通常为软件导出的「红果连接扩展」文件夹；不要选择整个项目目录。
3. 回到已登录的红果投稿后台（https://pugc.yueduwuxian.com/）。
4. 在剧单工作台中选择「连接原红果窗口」，复制软件显示的本机连接码。
5. 点击 Chrome 工具栏中的「剧单助手 · 红果连接」；选择你要使用的红果标签页，粘贴连接码。端口默认 18767，与软件显示的端口保持一致。
6. 点击「连接这个窗口」。扩展显示「已连接」后，软件才可使用这个标签页。核验账号时会额外打开一个后台标签页，不会把投稿表单切走。

已经安装时升级
由你在 chrome://extensions 对「剧单助手 · 红果连接」点击「重新加载」，再从扩展弹窗选择正确标签页并连接。无需删除扩展、重新安装或重新登录；连接码仍沿用本机保存的信息。
不要在任务传输中重载扩展。尚未保存或发布的网页内容应保留，软件不会为升级自行刷新或关闭页面。

每次使用
先打开剧单工作台和之前连接的红果标签页。如果原窗口的登录已过期，再在该窗口自行登录；扩展升级本身不要求重新登录。关闭所选标签页后，需要在扩展中重新选择并连接。
扩展会核对页面组件版本与扩展版本是否一致；旧页面组件不能悄悄替换成新版本继续操作。若提示版本不一致，请先保留页面内容，查看软件检查详情后再重新连接。

停止连接
点击扩展中的「断开」，或关闭剧单工作台。断开会停止本机素材中转和新的页面操作。已经交给平台的上传可能仍由平台继续处理，需要在红果页面查看实际状态。

权限与数据
扩展只申请 scripting、storage、alarms 权限，以及红果后台和本机 127.0.0.1 的访问权限。它不申请调试器、Cookie、所有网站、浏览历史权限。
连接码仅保存在本机扩展存储，不写入网页。软件可在所选红果页面读取可见内容、填写标题简介、选入封面和视频；不读取网页 Cookie、密码或浏览器用户目录。
本地媒体必须属于本次已核实的任务，由已配对软件生成临时随机地址。扩展后台 service worker 读取本机媒体，再经扩展消息按块交给页面组件；网页不直接请求本机媒体地址，不以等待网页的「本地网络」提示作为连接步骤。
每块最多256 KiB，核对顺序、偏移、声明大小和传输完整性。扩展拒绝任意外部媒体网址、磁盘路径和任意 JavaScript 指令，不增加现有权限。

当前文件限制
扩展模式顺序读取文件，单文件最大512 MiB，一次选择总计最大1 GiB。页面仍需构造完整File对象；超过限制会停止，不自动扩大限制或改用其他上传方式。

文件选择与平台接收
返回 count 与 files(name、size、type) 只确认文件选择结果，不能当作平台已接收、上传完成、保存或发布。
续传会逐项核对文件数量、名称和大小，再等待本批新增视频行及逐集明确完成状态；缺少文件确认信息会保留为结果不确定。
默认45秒仍无本批新增行时停止并保留记录；0行或文件确认不符也不能证明平台从未接收。已尝试的任务不得据此自动重传。
新剧上传填写后停在发布前；原合集续传停在保存前，由你在原页面检查。软件不点击最终保存或发布。

故障排查
「无法连接本机软件」：确认剧单工作台已打开连接模式，端口与连接码一致。
「标签页已离开红果后台」：回到正确的投稿页面，在扩展中重新连接。
「文件选择控件失效」：保留当前任务和页面，查看实际文件确认与平台状态；不要直接重复当前上传步骤。
「页面连接组件版本不一致」：软件会停止，不会替换监听、自动刷新或重建页面。先处理需要保留的网页内容，再在可重新打开的目标页连接。
「媒体传输不完整」：保持软件运行，查看软件中的文件校验和连接日志，不要手动将该条标为发布成功。

开发与核验
0.1.9 原合集续传
配套软件协商 album_append_v1、album_append_resume_v1、album_append_document_v1；同时核对当前页面组件版本。旧扩展或来源不明的页面会停止，不退回新建合集或覆盖原页面。
续传会在同一 Chrome 窗口新开独立合集管理页，按合集 ID 与完整名称核对后进入编辑。它只添加新视频，保留原视频、集序、标题、简介和封面，最后停在保存/发布前。
同一封面的临时签名或经验证的CDN分片轮换按同一资源核对；资源路径、稳定参数、原视频顺序及其他资料仍严格核对。存储对象字段顺序不代表资料变化，数组集序必须保持一致。
若账号、原单集或实际资料变化，或浏览器连接中断，任务保留供核对，禁止自动重建页面与重复上传。人工核对后的专用恢复流程须复验同任务、同页面来源及当前页面，不会清除历史上传尝试。
测试：node --test tests/test_extension_content.cjs
该测试使用本地虚构页面与伪媒体响应，不连接红果服务器，不代表真实红果上传已经验收。
